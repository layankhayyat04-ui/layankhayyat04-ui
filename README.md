### About

I build full-stack web applications and analyze data to drive business decisions. My work spans two connected tracks:

- **Full-stack development** — React, TypeScript, Angular, and Flutter, with Supabase/PostgreSQL backends
- **Business Intelligence & Analytics** — Power BI, DAX, SQL, and Python for turning raw data into decisions

Currently building an ERP system from scratch for a private medical clinic — covering scheduling, patient records, and admin workflows end-to-end.
